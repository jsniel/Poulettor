# Assembly Guide

## 1. Build the electronics

Install:

- ESP32-C3 Mini;
- DS3231 RTC module;
- two relay modules;
- connectors for buttons, limit switches and motor;
- status LED.

---

## 2. Build the mechanism

The prototype uses a DC gear motor with a spool.

The motor winds or unwinds a cord connected to the chicken coop door.

Install:

- a stable motor mount;
- a spool;
- a guide cord;
- a top limit switch;
- a bottom limit switch.

---

## 3. Test without animals

Before real use:

1. Open and close manually.
2. Check both limit switches.
3. Verify the motor timeout.
4. Test several full cycles.
5. Make sure the door cannot jam or injure animals.

---

## 4. Install in the coop

Mount the controller away from rain and dust.

Protect wiring and moving parts from chickens.
